
# Nidofy-Vite

This is a rewrite of my [portfolio site's frontend](https://github.com/ElectroBoy404NotFound/nidofy/tree/main/nidofy-frontend) in React.

Currently, I've implemented the home page and the poems view.


## Deploying

Once the repo is cloned, run `npm i` and `npm run build`. 

Then copy the contents of the dist directory to your web server.

## Demo

The live site can be accessed at https://nido.dino.icu/
